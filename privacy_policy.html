Privacy Policy

Claude Usage Monitor · Last updated May 2026 · Author: Trace Cohen
TL;DR: Your Claude usage data never leaves your browser. The only data sent externally is an anonymous install ping and, if you choose to fill it out, the contact form you voluntarily submit.

What data does the extension access?

Claude Usage Monitor reads your Claude.ai usage percentages (e.g. "72% used") and reset times from the claude.ai/settings/usage page. It reads these values by observing the page you're already viewing — the same way you would read them yourself.

Where does usage data go?

Nowhere outside your device. All usage data is stored exclusively in chrome.storage.local — a sandboxed, browser-local store only this extension can read. It is never uploaded to any server, sent to the developer, shared with third parties, or used for advertising.

What is sent externally?

1. Install notification (automatic)
When you install the extension, an anonymous ping is sent to Formspree containing only the word "install" and the current timestamp. No personal information, browser data, or usage data is included. This helps the developer track how many people have installed the extension.

2. Contact form (optional, user-initiated)
The Settings page includes a voluntary form asking for your first name, last name, email address, and zip code. This information is only submitted if you fill it out and click "Subscribe to updates." It is sent to Formspree and forwarded to the developer's email address. It is used solely to send product update emails and is never sold or shared with third parties.

Optional local server (SwiftBar / menu bar)

If you install the optional local Python server for menu bar support, usage data is sent over localhost (127.0.0.1:39571) only — it never leaves your machine. This is entirely optional.

Permissions explained

  • storage — saves usage history and preferences locally in the browser
  • notifications — shows desktop alerts when you approach a usage limit
  • alarms — schedules periodic background checks (every 5–20 min)
  • tabs — opens a silent background tab to refresh usage data
  • offscreen — plays an optional audio beep warning
  • host permission: claude.ai — reads the usage page
  • host permission: localhost:39571 — optional menu bar server, only used if you run it

Third-party services

The extension uses Formspree to process form submissions. Formspree's privacy policy governs how they handle submitted data.

Open source

The full source code is publicly available at github.com/TraceCohenTech/claude-usage-monitor. You can audit exactly what the extension does.
