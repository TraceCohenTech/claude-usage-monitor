Privacy Policy

Claude Usage Monitor · Last updated May 2025 · Author: Trace Cohen
TL;DR: This extension collects nothing. All data stays in your browser. No servers, no tracking, no ads.

What data does the extension access?

Claude Usage Monitor reads your Claude.ai usage percentages (e.g. "72% used") and reset times from the claude.ai/settings/usage page that you have already opened in your browser. It reads these values by observing the page you're already viewing — the same way you would read them yourself.

Where does that data go?

Nowhere outside your device. All usage data is stored exclusively in chrome.storage.local — a sandboxed, browser-local store that only this extension can read. It is never:

  • Uploaded to any server
  • Sent to the extension developer
  • Shared with third parties
  • Used for analytics or advertising

Optional local server (SwiftBar / menu bar)

If you choose to install the optional local Python server for menu bar support, data is sent over localhost (127.0.0.1:39571) only — it never leaves your machine. This component is entirely optional and is not installed by default.

Permissions and why they're needed

  • storage — saves your usage history and preferences locally in the browser
  • notifications — shows desktop alerts when you approach a limit
  • alarms — schedules periodic background checks (every 5–20 min)
  • tabs — opens a silent background tab to refresh usage data; reads tab URLs to avoid duplicate opens
  • offscreen — plays an optional audio beep warning using the Web Audio API
  • host permission: claude.ai — needed to read the usage page and show the in-page warning banner
  • host permission: localhost:39571 — optional; only used if you run the local menu bar server

No accounts, no sign-in

The extension requires no account, no login, and no personal information of any kind. It works entirely offline after installation.

Open source

The full source code is publicly available at github.com/tracecohen/claude-usage-monitor. You can audit exactly what the extension does.
